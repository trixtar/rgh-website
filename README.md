# Personal Portfolio

A multilingual personal portfolio built with **Next.js 16 (App Router)**, **next-intl**, and **Tailwind CSS**.

## Features

- Internationalized content (EN / ES)
- Locale-specific routing and metadata
- Tailwind-based responsive design
- Mobile-first navigation
- Video gallery with modal playback
- SEO-friendly metadata

## Tech Stack

- Next.js 16+
- React 19
- TypeScript
- next-intl (i18n routing)
- Tailwind CSS
- pnpm (package manager)

## Project Structure

- `app/[locale]` – localized pages
- `components/` – reusable UI components
- `i18n/` – routing and navigation helpers
- `messages/` – translation files

## Getting Started

### Install dependencies

```bash
pnpm install
```

### Run dev server

```bash
pnpm dev
```
